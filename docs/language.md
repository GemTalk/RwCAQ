# Rowan Component Activation Query

Rowan Component Activation Queries (CAQ) answer a question: Should this component be loaded? As a consequence, all valid expressions evaluate to a boolean value.

## Language Constructs

- Types
  - Booleans
  - Versions
- Variables
- Binary Operators
  - Equality
  - Logic
  - Comparison
- Syntic Sugar
  - Range
    - Open Range
    - Closed Range
    - Subversion Range
  - Parenthesis

## Variables

- Explicit
- Implicit
